## English description
Translate selected website text directly in the Firefox sidebar. Connect your own compatible Chat Completions API, enter an API key if needed, and choose a model or routing preset. Includes Russian/English UI, automatic language detection, more than 70 translation languages, a local 30-day translation cache, and a FreeLLMAPI-only button to request an alternative translation. Shows the answering model and its upstream provider when supplied by the API. No ads, no tracking and no developer-operated relay. FreeLLMAPI is recommended for a pool of free models, but not required. Some providers are paid and their free usage limits may vary.
