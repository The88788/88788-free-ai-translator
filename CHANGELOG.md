# 88788 Free AI Translator v0.4.1

**Release date:** October 15, 2026
**Platform:** Mozilla Firefox 140+
**Status:** Mozilla Signed & Approved

## English

First officially signed release of **88788 Free AI Translator**, a free Firefox extension for translating selected webpage text using your own OpenAI-compatible API.

### What's New in v0.4.1

- Added display of the actual AI provider alongside the model name.
- Added support for reading provider information from FreeLLMAPI response headers.
- Provider and model information are now preserved in the local translation cache.
- Improved compatibility with OpenAI-compatible API responses.
- Prepared the extension for independent distribution and automatic updates.

### Main Features

- Translate selected text directly in the Firefox sidebar.
- Support for 75 translation languages.
- Russian and English user interface.
- Connect your own OpenAI-compatible API, including OpenRouter, Groq, Gemini and FreeLLMAPI.
- Select a custom model or routing preset.
- Smart local translation cache: up to 200 entries, retained for up to 30 days.
- Automatic retries for temporary API errors.
- Request an alternative translation when using FreeLLMAPI.
- No advertisements, subscriptions or analytics.

**Note:** An API key from a compatible provider is required. Free usage depends on the provider's available quotas.

## Русский

Первый официально подписанный Mozilla выпуск **88788 Free AI Translator**, бесплатного расширения для Firefox, позволяющего переводить выделенный текст на веб-страницах с использованием собственного OpenAI-совместимого API.

### Новое в версии 0.4.1

- Добавлено отображение фактического AI-провайдера рядом с названием модели.
- Реализовано получение информации о провайдере из заголовков ответа FreeLLMAPI.
- Информация о модели и провайдере сохраняется в локальном кеше переводов.
- Улучшена обработка ответов OpenAI-совместимых API.
- Подготовлена поддержка независимого распространения и автоматических обновлений.

### Основные возможности

- Перевод выделенного текста в боковой панели Firefox.
- Поддержка 75 языков перевода.
- Интерфейс на русском и английском языках.
- Подключение собственного API: OpenRouter, Groq, Gemini, FreeLLMAPI и других совместимых сервисов.
- Выбор модели или маршрута.
- Умный локальный кеш: до 200 записей со сроком хранения до 30 дней.
- Автоматические повторные запросы при временных ошибках API.
- Возможность получения альтернативного перевода через FreeLLMAPI.
- Без рекламы, подписок и аналитики.

**Примечание:** для использования необходим API-ключ совместимого провайдера. Бесплатные квоты зависят от выбранного сервиса.
